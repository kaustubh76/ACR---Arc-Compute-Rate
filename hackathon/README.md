# Hackathon material — preserved, not maintained

ACR was built across two hackathons. Everything submitted to them lives here so the
repository's front door can be for users. Nothing in this folder is kept current: numbers,
addresses and counts are as they stood on the submission day, and the CI claims audit no
longer checks them.

| folder | event | frozen at |
|---|---|---|
| [`arc-circle-2026/`](arc-circle-2026/) | Arc × Circle Agentic Economy, August 2026 — the pitch deck, brief, judge-facing status and demo script | tag `v1.0-submission` |
| [`ethonline-2026/`](ethonline-2026/) | ETHGlobal ETHOnline 2026, Continuity track — Machine TCA, the continuity diff, sponsor feedback | tag `ethonline-2026` |
| [`accelerator/`](accelerator/) | the accelerator application and plan | — |
| [`canvases/`](canvases/) | superseded architecture canvases; the live one is [`../acr_architecture.excalidraw`](../acr_architecture.excalidraw) | — |

To see the repository exactly as a judge saw it: `git checkout ethonline-2026`. The state
immediately before this folder existed is tag `pre-hygiene`.

The documentation that *is* maintained starts at [`../docs/README.md`](../docs/README.md).
